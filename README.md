# aniketghonge.com

Personal portfolio site — technology operations & portfolio strategy, impact highlights, and live AI-built engineering work.

Static site, no build step: `index.html` is the entire app (inline CSS + vanilla JS tab navigation).

## Run locally

Open `index.html` directly in a browser, or serve it:

```
npx serve .
```

## Deploy

Deployed via Vercel, connected to this GitHub repo for auto-deploy on push to `main`. Custom domain: aniketghonge.com.
